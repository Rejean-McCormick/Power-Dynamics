# Core Ontology

The canonical ontology is:

> **Resource / Asset → Potential → Capacity → Puissance → Power Relation → Effect → Return**

This is not a claim that every real process is linear. It is a conceptual separation that prevents category errors.

- **Resource / asset** — something available or accumulated that may support action.
- **Potential** — what could become realistically possible because those resources exist.
- **Capacity** — an organized ability under defined conditions.
- **Puissance** — a capacity that is effectively mobilizable under actual conditions.
- **Power relation** — a relation in which one actor's or system's puissance changes another's effective possibilities.
- **Effect** — the realized change.
- **Return** — a reusable asset created or preserved by the effect.

### Knowledge example

`research corpus → potential understanding → organized expertise → epistemic puissance → advisory/recognition relation → changed decision → credibility + memory`

### Money example

`financial stock → potential purchasing options → liquid capacity → economic puissance → allocation/bargaining relation → funded project → infrastructure + revenue`

The ontology does not make relational power morally negative. Power may enable, coordinate, recognize, protect, allocate, constrain, or dominate.
