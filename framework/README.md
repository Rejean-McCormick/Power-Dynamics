# Framework

This directory is the **analytical engine behind the kOA Power Show**.

The showcase begins with what kOA can make possible. The framework supplies the precision needed to explain those capabilities without treating every resource, capability, influence, authority, or dependency as the same thing.

4. [`03-three-axis-model.md`](03-three-axis-model.md) — state × dynamic × domain.
5. [`04-power-ecology.md`](04-power-ecology.md) — feedback among capabilities, relations, returns, dependencies, and alternatives.
