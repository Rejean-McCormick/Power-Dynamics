# Framework

The framework answers four questions in order:

1. **What exists?** — resources, potential, capacity, puissance, power relations, effects, returns.
2. **What is happening?** — formation, mobilization, composition, conversion, compounding, capture, contestation, evolution, decay.
3. **Where is it happening?** — economic, epistemic, technical, political, narrative, reputational, administrative, etc.
4. **Under what constitutional conditions?** — scope, auditability, contestability, substitutability, exit, federation, revocability, and branch mobility.

The files in this directory define the common language used throughout the repo.
