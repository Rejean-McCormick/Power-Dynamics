# Compounding, Regeneration, and Decay

Compounding occurs when the outputs of one cycle reduce the cost or increase the productivity of later cycles.

Knowledge is especially capable of compounding because it can often be copied without consuming the original. Institutional memory compounds when later actors can inherit prior reasoning instead of repeating discovery. Code compounds when a tool automates work that previously consumed human time. Networks compound when one trusted relationship opens access to additional relationships.

A simplified loop is:

```text
capability
→ action
→ evidence + experience + assets
→ lower future coordination cost
→ greater capability
```

Compounding has both positive and negative forms. Wealth can compound into greater market access. Reputation can compound into more visibility and then more reputation. A dominant branch can accumulate network effects that make alternatives progressively harder to discover.

Therefore the repo also tracks **decay**. Expertise becomes stale. Reputation can outlive relevant performance. Institutional memory can fossilize obsolete assumptions. A branch can remain dominant because of inertia rather than current fitness.

Healthy compounding requires mechanisms for revision, time sensitivity, branch mobility and evidence that can challenge accumulated advantage.
