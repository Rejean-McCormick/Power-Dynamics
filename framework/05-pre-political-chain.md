# Pre-Political Power

Formal decisions are only one stage in a longer chain:

> **Meaning → Knowledge → Visibility → Credibility → Agenda → Deliberation → Decision → Execution → Memory**

Each stage is a locus of puissance and potentially of relational power.

Definitions shape what can be perceived. Validation shapes credibility. Discovery shapes visibility. Ranking shapes attention. Agenda setting shapes what enters decision. Administrative routing shapes what becomes executable. Memory shapes what later actors inherit.

A system can preserve one-person-one-vote while still concentrating major influence upstream in search, ranking, classification, moderation, recommendation, defaults, identity, or workflow routing.

Power Dynamics therefore studies the entire mediation chain rather than treating the ballot or final command as the only politically meaningful event.
