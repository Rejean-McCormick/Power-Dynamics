# Stock, Capacity, Flow, and Return

An earlier useful distinction is preserved in refined form.

- **Stock** — what has accumulated.
- **Capacity** — what the actor or system is organized to do.
- **Puissance** — what it can effectively mobilize under current conditions.
- **Flow** — the practical movement or throughput of resources, action, information, or effects.
- **Return** — what comes back into the system and can be reused.

The combined model is:

> **Stock → Potential → Capacity → Puissance → Flow / Relation → Effect → Return → New Stock**

This is especially useful for compounding analysis. A large stock can remain politically weak if it cannot be mobilized or converted; a small initial stock can compound through code, experience, methods, reputation, and network assets.
