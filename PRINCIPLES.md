# Principles

These are **governing analytical invariants**, not claims that any implementation already satisfies them perfectly.

1. **Power is effective possibility.** Formal permission and practical capability are different.
2. **Power is multidimensional.** No single resource, institution or score represents power as a whole.
3. **Power can be generative.** Knowledge, coordination and reusable infrastructure can create capabilities that did not previously exist in any individual actor.
4. **Power can leave assets behind.** Action may create code, knowledge, relationships, credibility, memory, tools, money or optionality that can be reinvested.
5. **Returns matter.** Always ask who receives the assets generated by collective activity.
6. **No perfect human metric.** Competence, ethics, credibility, contribution and legitimacy cannot be perfectly measured.
7. **A reading is not the thing measured.** `score ≠ person`, `score ≠ competence`, `score ≠ ethics`, and `score ≠ truth`.
8. **Support is not evidence.** Popularity, expertise, adoption, performance and legitimacy are distinct dimensions.
9. **Dominance is provisional.** A dominant branch is not thereby true, perfect or permanently legitimate.
10. **No silent power conversion.** Expertise should not automatically become sovereignty; wealth should not automatically become votes; reputation should not become truth; technical control should not become political authority.
11. **Strong capability, weak sovereignty.** Useful functions may be strong while remaining scoped, contestable and replaceable.
12. **Forkability must be effective.** Portability, interoperability, data continuity, discoverability and practical operability matter more than a formal right to copy code.
13. **Plurality without fragmentation.** Multiple branches may differ while retaining a shared grammar sufficient for comparison and association.
14. **Complementarity can outperform convergence.** A scientific, legal, local, technical and historical representation may each add value without one becoming universal.
15. **Improvement must be demonstrable.** A branch claiming superiority should state the dimension, evidence, trade-off and context in which it is better.
16. **The core should protect evolution, not freeze outcomes.** Stable lineage, provenance and interoperability can coexist with evolving policies and implementations.
17. **No terminal authority.** Imperfection is unavoidable; what must be resisted is imperfection becoming permanent simply because alternatives cannot emerge.
18. **Architecture is governance before governance is written.** Defaults, schemas, keys, registries, routing, permissions and interfaces distribute power even when no political language is used.
