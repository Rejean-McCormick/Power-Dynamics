# Power Routing, Sharing, and Devolution

Power Dynamics does not stop at **how much power kOA can generate**.

It asks:

> **Where does the capability, leverage, authority, return, and optionality created by kOA actually go?**

A system can empower users while still making its operator indispensable. Power routing therefore examines four destinations separately:

```text
CAPABILITY → who can do more?
AUTHORITY  → who can decide or control more?
RETURNS    → who receives reusable value?
OPTIONALITY→ who can refuse, leave, reproduce, fork, or wait?
```

## Core routing mechanisms

| Source of leverage | Concentrating default | Routing / sharing mechanism | Intended destination |
|---|---|---|---|
| Founder knowledge | permanent founder dependency | documentation, schemas, protocolization, tests | maintainers, branches, independent operators |
| Founder / persona authority | deference becomes policy or truth immunity | published fallibility, contestation, opposition rehearsal | independent public judgment |
| Reference knowledge branch | reference becomes truth monopoly | forkability, lineage, evidence comparison | plural epistemic capacity |
| Narrative attention | founder/persona centrality | explicit ethics, self-critique, attribution, anti-domination | public principles, procedures, critical readers |
| Brand | trademark becomes protocol sovereignty | brand stewardship separated from protocol | protocol commons + bounded official brand |
| Koali credibility infrastructure | one owner defines standing | plural distributions, portable evidence, explicit policy identity | communities, domains, alternative operators |
| Expertise | expert becomes ruler | baseline + bounded advisory readings | informed public judgment |
| Knowledge validation | one owner of truth | provenance, reader policies, competing Kristals | plural epistemic capability |
| Infrastructure | operator becomes unavoidable | self-hosting, capsules, federation, rollback, substitution | local operators / communities |
| Money | wealth buys rule | one-member-one-vote / allocation firewalls | common funding without pay-to-rule |
| Workflow control | administrator becomes policymaker | scoped mandate, audit, appeal, revocability | execution without mandate capture |
| AI capability | model becomes hidden sovereign | explicit role boundaries, provenance, human authority | cognitive amplification without institutional sovereignty |
| Dominant branch | incumbency becomes final | branch mobility, lineage, recombination | viable alternatives |

## Ethical fiction as power routing

The fiction is not only a vehicle for symbolic puissance. It also publishes limits on that puissance.

The source corpus includes explicit commitments around:

- clarity of intention;
- respect for living beings;
- vigilance against monopoly, domination, and manipulation;
- recognition of contributors and sharing merit;
- self-mockery and refusal to sanctify the Klown;
- revision, criticism, adaptation, and transmission rather than dogma.

Power Dynamics calls this **narrative self-binding**.

```text
symbolic power
→ public ethical commitments
→ stable grounds for criticism
→ reduced freedom for arbitrary reinterpretation
```

Self-binding is not proof of compliance. It makes the exercise of power **more legible and criticizable**.

## Koali: from property to protocol ecology

Current architect-confirmed design direction:

> **Koali should not remain a terminal personal credibility authority. Its useful capability should be duplicable, shareable, branchable, and operable through plural distributions around interoperable structures.**

The desired transition is:

```text
founder-created capability
→ explicit kernel / contracts
→ portable evidence and history
→ explicit policy identity
→ multiple distributions
→ interoperability
→ independent operation
→ branch mobility
```

This is not founder erasure. It is **ownership decoupling**: the useful function can outgrow exclusive ownership of the first implementation.

## Power sharing is not flatness

The goal is not to make everyone equally expert, equally responsible, or equally authoritative.

The goal is:

> **Useful asymmetry without terminal dependency.**

A maintainer may have more technical authority within a defined scope. An expert may have more epistemic relevance in a defined domain. A coordinator may have routing authority for a workflow. None of those roles should silently acquire unrelated sovereignty.

## Routing and conversion firewalls

Routing is strongest when paired with conversion limits:

```text
expertise → advice                  ✓
expertise → sovereign vote weight   ✗

money → funding                     ✓
money → political standing          ✗

brand → attention                   ✓
brand → truth                       ✗

infrastructure → capability         ✓
infrastructure → captivity          ✗

execution → implement mandate       ✓
execution → redefine mandate        ✗
```

## Canonical routing test

For every important kOA mechanism:

1. What puissance does it create?
2. Where would that puissance naturally concentrate?
3. What relational power does that concentration create?
4. What capability can be routed outward instead?
5. What authority must remain scoped?
6. Who receives the returns?
7. Who receives exit / substitution / fork optionality?
8. What evidence proves that the routing is practical rather than merely formal?
