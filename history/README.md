# Genealogy of the Power Model

The corpus shows an evolution rather than one fixed doctrine.

Broadly:

1. **diagnosis of dependency and structural abuse**;
2. **experiments in strong corrective economic institutions**;
3. **language, narrative, alliance, and empowerment**;
4. **knowledge-to-action architecture**;
5. **non-domination, semantic sovereignty, bounded expertise, auditability, federation**;
6. **Power Dynamics synthesis: capability creation plus constitutionalized evolution**.

The repository preserves tensions instead of retroactively making all documents agree.
