# From Dependency to Compounding Capability

The negative and positive sides of the corpus mirror one another.

`Abuser l'humanité` asks how systems make people dependent, exhausted and procedurally weak. kOA asks how knowledge, deliberation, execution and memory can become reusable collective capacity.

The conceptual bridge is effective possibility. Dependency narrows it. Knowledge, association, infrastructure and memory can expand it. Returns and reinvestment allow that expansion to persist across cycles rather than disappear after each action.
