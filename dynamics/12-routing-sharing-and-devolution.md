# Routing, Sharing, and Devolution

Routing is the dynamic through which newly generated capability, authority, returns, or optionality are directed toward particular actors, levels, protocols, or communities.

## Canonical pattern

```text
new capability / leverage
→ default locus of accumulation
→ routing mechanism
→ redistributed capability / authority / returns / optionality
```

Examples:

```text
founder mastery
→ protocolization
→ distributed mastery
```

```text
expertise
→ bounded advisory channel
→ informed public judgment
```

```text
infrastructure
→ self-hosting / federation
→ local continuity and substitution
```

```text
money
→ common pool
→ democratic allocation
```

```text
symbolic attention
→ explicit ethical self-binding
→ public grounds for criticism and reinterpretation
```

## Sharing

Sharing occurs when multiple actors gain effective use of a capability or right without requiring one terminal owner of the function.

Sharing should be tested practically, not only legally:

> Can others actually understand, operate, reproduce, adapt, and continue the capability?

## Devolution

Devolution is a durable movement of effective control from a central locus toward local, plural, or lower-level loci.

It can involve:

- local semantic governance;
- self-hosted infrastructure;
- distributed maintainership;
- community-run Koali distributions;
- branch autonomy;
- local decision rights;
- portable evidence and memory.

## Failure modes

- nominal openness with impractical replication;
- distributed software but centralized identity;
- portable data but non-portable credibility/history;
- self-hosting without discoverability;
- forkability without branch mobility;
- shared capability with centralized authority;
- shared authority with centralized returns.

Routing therefore must track **capability, authority, returns, and optionality separately**.
