# Power Externalities and Scale

Success can create power even without an explicit decision to concentrate it.

A useful system can become a default. A default can become a standard. A standard can create dependency. A credibility system can become expected by employers. A platform can become the place where discoverability occurs. A brand can become a de facto certification mark.

This is a **power externality**:

`usefulness → adoption → network effects → standardization → dependency / leverage`

Scale also changes the political meaning of mechanisms. A ranking rule affecting 100 users and the same rule affecting 100 million users are not constitutionally equivalent even if the code is identical.

Analyze scale transitions:

- local tool;
- network infrastructure;
- institutional standard;
- ecosystem dependency;
- systemic infrastructure.

At each transition, reassess scope, branch mobility, substitution cost, auditability, and conversion firewalls.
