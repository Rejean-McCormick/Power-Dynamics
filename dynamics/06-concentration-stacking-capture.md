# Concentration, Stacking, and Capture

Concentration is multidimensional. An actor can be decentralized economically while centralized technically, or plural in formal governance while dependent on one trust root, identity provider, brand, maintainer, or deployment key.

## Stacking

Stacking occurs when multiple legitimate functions accumulate in one node.

`banking + identity + certification + philanthropy + platform access → cross-domain leverage`

No individual function must be abusive for the stack to create new dependency.

## Capture

Capture occurs when control over one legitimate function is converted into durable influence outside its intended mandate:

> **Functional Control → Cross-Domain Power**

Capture is a gradient, not merely a binary state. Signals include mandate drift, default expansion, dependency growth, weakened substitution, recognition loops, reduced branch mobility, and increased exit cost.

The constitutional aim is not impossible-to-capture systems. It is **non-terminal capture**.
