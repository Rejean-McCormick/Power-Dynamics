# Conversion and Power-Conversion Firewalls

Conversion is one of the most important dynamics in Power Dynamics.

Examples:

`knowledge → credibility → visibility → opportunity`

`money → infrastructure → distribution → influence`

`brand → attention → affiliation → revenue`

`technical administration → defaults → agenda leverage`

`adoption → dependency → standard-setting power`

The question is not whether conversion exists but **which conversions are visible, legitimate, bounded, and contestable**.

Canonical firewalls:

| Useful conversion | Prohibited automatic conversion |
|---|---|
| expertise → advice | expertise → universal sovereignty |
| money → funding | money → extra votes |
| brand → attention | brand → truth |
| credibility → discoverability | credibility → unquestionable authority |
| administration → maintenance | administration → self-expanding mandate |
| narrative → mobilization | narrative → legitimacy by itself |

Different forms of puissance should remain composable without becoming silently convertible into unrelated power.
