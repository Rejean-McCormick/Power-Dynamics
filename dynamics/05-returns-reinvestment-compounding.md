# Returns, Reinvestment, and Compounding

Action can leave reusable assets behind.

> **Puissance → Action → Result → Return → Reinvestment → Greater Future Puissance**

Returns include money, code, tools, experience, methods, evidence, data, memory, credibility, relationships, brand recognition, standards, and optionality.

The key question is:

> **Who receives the returns generated by collective activity?**

An extractive system may channel collective activity into assets controlled by a narrow owner. An empowering system may return more value to participants, shared infrastructure, public memory, reusable knowledge, or interoperable commons.

Compounding can also entrench incumbents. A healthy loop:

`Contribution → Evidence → Recognition → Opportunity → More Contribution`

can degrade into:

`Recognition → Visibility → Opportunity → Recognition`

where incumbency reproduces itself.
