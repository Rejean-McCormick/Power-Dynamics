# Propagation and Coupled Loops

Compounding explains how returns increase future capability.

Propagation explains how those returns can activate capability **elsewhere**.

> **Compounding deepens capability. Propagation spreads or activates capability. Coupled propagation lets several loops exchange returns.**

A general sequence is:

```text
resource / capability A
→ action
→ return X
→ transfer / reuse
→ lower activation barrier for B
→ capability B
→ return Y
→ reinvestment into A or C
```

Propagation therefore extends the dynamic sequence after returns and compounding:

> **Formation → Mobilization → Composition → Conversion → Effects → Returns → Compounding → Propagation → Concentration / Contestation → Diversification / Evolution → Routing / Sharing**

The primary risks are:

- positive feedback producing capture;
- cross-loop hidden dependencies;
- prestige / credibility self-reproduction;
- recognition gatekeepers becoming mandatory;
- coordination layers accumulating hidden assignment authority;
- standards or interface choke points;
- founder bottlenecks;
- network effects that reduce exit;
- growth in content or integration complexity faster than validation capacity.

The constitutional target is not weak capability. It is:

> **distributed compounding with bounded sovereignty and practical exit.**
