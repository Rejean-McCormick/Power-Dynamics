# Architect-Confirmed Design Notes

This file records current design intentions that have been explicitly confirmed during repository development but are not yet backed by a canonical technical specification in the supplied corpus.

They should not be cited as if they were already implemented facts.

## Koali ownership and distribution

Current intention:

> Koali should not remain the exclusive personal property or terminal credibility authority of its founder. Its useful capability should be duplicable, shareable, branchable, and capable of plural distributions around interoperable structures.

Technical evidence still needed:

- kernel / interoperability specification;
- evidence portability model;
- distribution identity;
- policy versioning;
- branch / fork procedure;
- registry / discovery design;
- brand / trademark relationship to protocol implementations.

## Ethical principles inside fiction

Current intention and source-backed practice:

> The narrative layer explicitly publishes ethical principles rather than leaving them as private founder intent.

S02 provides direct source support for a living ethical code, vigilance against monopoly and domination, public recognition, self-mockery, revision, and non-dogmatic transmission.


## Reference Kristal stewardship and worldview forks

Current intention:

> A principal encyclopedic Kristal is envisioned as an institutionally stewarded reference corpus, including a proposed UNESCO stewardship role, while remaining forkable into incompatible worldview, cultural, religious, fictional, or experimental branches.

This records an intended stewardship model, **not an existing UNESCO agreement, endorsement, or deployment**.

The intended constitutional distinction is:

```text
reference stewardship ≠ ownership of truth
forkability ≠ equal evidentiary support
```

Technical evidence still needed:

- reference-branch governance specification;
- fork and lineage rules;
- reader-policy model;
- evidentiary comparison across branches;
- institutional stewardship / handoff mechanism.

## Founder opposition rehearsal

Current intention:

> kOA should not only permit disagreement with its founder; it should establish a practiced precedent for organized, legitimate opposition to a founder-backed proposal.

A proposed civic resilience drill uses an otherwise coherent political platform containing one conspicuously abusive tattoo-prohibition / compulsory-removal policy. The intended output is a reusable counterpower pathway, not adoption of the policy.

The design objective is to test whether symbolic founder authority can be prevented from becoming truth or policy immunity.

## Epistemic authority corruption drill

Current intention:

> A deliberately false flat-Earth Kristal branch should be used as an adversarial epistemic stress test to study how weak, dependent, misleading, or fabricated authority signals can accumulate into apparent credibility and consensus.

The primary intended output is a postmortem taxonomy of corruption patterns and detection failures. This note records the threat-model direction, not an operational procedure for deceiving external institutions or audiences.
