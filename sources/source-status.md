# Source Status

`CURRENT-CORE` and `CURRENT-EXPERIMENTAL` describe recent design direction. `CURRENT-DESIGN-NOTES` records architect-confirmed current mechanisms or intentions that still require independent technical or adoption evidence. `LEGACY-PROPOSAL` identifies earlier proposals retained for historical and stress-test value. `ANALYTICAL-RECONSTRUCTION` identifies synthesis rather than primary architecture.

Status is not truth ranking. A legacy proposal can still expose a useful mechanism, and a recent analytical document is not automatically a canonical technical specification.

See [`corpus-map.md`](corpus-map.md) for per-source classification.
