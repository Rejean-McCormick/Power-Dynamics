# Source Status

`CURRENT-CORE` and `CURRENT-EXPERIMENTAL` describe recent design direction. S29–S30 are `CURRENT-DESIGN-NOTES`: architect-confirmed working directions that still require independent implementation or impact evidence. `CURRENT-DESIGN-NOTES` records architect-confirmed current mechanisms or intentions that still require independent technical or adoption evidence. `LEGACY-PROPOSAL` identifies earlier proposals retained for historical and stress-test value. `ANALYTICAL-RECONSTRUCTION` identifies synthesis rather than primary architecture.

Status is not truth ranking. A legacy proposal can still expose a useful mechanism, and a recent analytical document is not automatically a canonical technical specification.
