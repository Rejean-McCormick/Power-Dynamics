# Capability and Power Conversion Chains

Power rarely remains in one domain. Resources and forms of puissance can be converted into other resources, opportunities, and relations of power.

## Common chains

```text
knowledge
→ credibility
→ visibility
→ opportunity
→ resources
→ better tools
→ more knowledge
```

```text
brand
→ attention
→ affiliation
→ sales / funding
→ infrastructure
→ reach
→ stronger brand
```

```text
network
→ collaborators
→ execution
→ results
→ reputation
→ broader network
```

```text
technical control
→ control of defaults
→ user dependence
→ agenda influence
```

```text
money
→ infrastructure
→ distribution
→ attention
→ political influence
```

## Conversion is not automatically illegitimate

Systems need conversion. Expertise should influence advice. Money should fund work. Reputation can help discovery. Technical administration is needed to maintain infrastructure.

The danger is **automatic cross-domain conversion**.

Examples:

- expertise becoming political sovereignty;
- money becoming more votes;
- brand becoming truth;
- technical maintenance becoming control of political outcomes;
- credibility becoming unquestionable authority;
- infrastructure becoming ownership of users.

That is why Power Dynamics uses **conversion firewalls** rather than trying to eliminate conversion itself.

## Power stacking

When one actor controls several conversion points, legitimate functions can stack into cross-domain leverage.

```text
finance
+ identity
+ certification
+ platform access
+ philanthropy
→ high cross-domain leverage
```

The issue is not that any one function is illegitimate. The issue is what the combined position makes possible.
