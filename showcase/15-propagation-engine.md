# The Propagation Engine

kOA does not rely on one flywheel.

It can contain several partially independent loops whose outputs become one another's inputs.

```text
BUILD
  ↓
USEFUL CAPABILITY
  ↓
WORLD / DEMONSTRATION
  ↓
UNDERSTANDING
  ↓
PILOT
  ↓
EVIDENCE
  ├────────→ CREDIBILITY ───────→ INSTITUTIONAL ACCESS
  │                                  ↓
  │                              MORE PILOTS
  │
  └────────→ OPERATIONAL DEMAND ─→ MANAGED SERVICE
                                     ↓
                                   REVENUE
                                     ↓
                                DEVELOPMENT
                                     ↓
                             GREATER CAPABILITY
                                     ↺
```

Other loops attach:

```text
pilot → training material → operator → independent deployment → more pilots
```

```text
integration → more capability → more usefulness → demand for integration
```

```text
objects → SmartVote signal → better discovery → reuse → more objects
```

```text
new language → new community → contribution → better language resources
```

```text
founder work → protocols / tools / documentation → autonomous operators
→ lower founder bottleneck → more parallel work
```

The most important property is therefore not “many mechanisms.”

> **The mechanisms share returns.**

The constitutional requirement is equally important:

> **Positive feedback must increase distributed capability faster than it increases terminal dependency.**
