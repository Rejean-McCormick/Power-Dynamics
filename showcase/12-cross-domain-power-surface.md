# Cross-Domain kOA Power Surface

kOA's largest effects appear when capability crosses domain boundaries.

## Cross-domain graph

```text
SEMANTIC
   ↓
EPISTEMIC → CREDIBILITY → VISIBILITY → AGENDA → POLITICAL
    ↓             ↓            ↓                     ↓
 COGNITIVE      NETWORK      NARRATIVE            ALLOCATION
    ↓             ↓            ↓                     ↓
 DECISION ← COLLECTIVE ← AFFILIATION ← BRAND      ECONOMIC
    ↓                                                  ↓
ADMINISTRATIVE → EXECUTION → RETURNS → MEMORY → COMPOUNDING
    ↓                                                  ↓
TECHNICAL / INFRASTRUCTURAL ← FUNDING ← MONETARY / ECONOMIC
    ↓
FEDERATION → SUBSTITUTION → FORK → EVOLUTION
```

No arrow means automatic legitimacy. Each arrow is a **possible conversion path** that must be made explicit and governed.

## High-leverage conversion chains

### Knowledge to political influence

```text
knowledge
→ credibility
→ visibility
→ agenda access
→ political influence
```

### Money to political leverage

```text
money
→ infrastructure
→ reach
→ attention
→ organizational capacity
→ political leverage
```

### Brand to economic capacity

```text
brand
→ attention
→ affiliation
→ purchases / funding
→ infrastructure
→ development capacity
```

### Technical control to de facto governance

```text
technical administration
→ defaults
→ compatibility
→ dependency
→ inability to substitute
→ quasi-sovereign leverage
```

### Memory to future power

```text
institutional memory
→ precedent
→ lower coordination cost
→ faster action
→ stronger results
→ greater credibility
```

## Why the map matters

A component can be perfectly legitimate inside its original function and still become dangerous through conversion.

This is the basis of **Power Stacking** and **Capture**:

> **Functional Control → Cross-Domain Power**

The appropriate question is not merely “is this component democratic?” but:

> **What other domains can control of this component buy?**

## Routing layer

The kOA response is to combine:

- function separation;
- conversion firewalls;
- scoped authority;
- protocolization;
- self-hosting;
- portable evidence;
- baseline/advisory separation;
- explicit ethics;
- branch mobility;
- verification, contestation, substitution, and exit.

See [`14-power-conversion-and-routing-map.md`](14-power-conversion-and-routing-map.md).
