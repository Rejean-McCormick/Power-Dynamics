# kOA Component Power Matrix

Every component should be read across five questions:

1. What resource does it organize?
2. What puissance does it generate?
3. In which domain does relational power emerge?
4. Into what other domains can that power convert?
5. How is capability routed or counterpower preserved?

| Component | Primary domains | Generated / amplified puissance | Possible relational power | Cross-domain conversion | Routing / counterweights |
|---|---|---|---|---|---|
| SemantiK / SenTient | semantic, epistemic | classification, ambiguity resolution, translation | framing, admissibility, ontology power | meaning → agenda / enforcement | explicit ontologies, provenance, local governance, alternatives |
| Kristal | epistemic, mnemonic | structured knowledge, provenance, reusable memory | validation, canon, trust-root, standard-setting | knowledge → credibility → visibility | portability, lineage, competing Kristals, reader-policy plurality |
| Konnaxion | information, attention, network | circulation, association, discoverability | ranking, moderation, visibility, agenda, access | attention → affiliation / opportunity / politics | explicit policies, export, federation, alternative discovery paths |
| Koali / EkoH | credibility, reputation | evidence and expertise legibility | standing, certification, opportunity | credibility → visibility / funding / influence | domain bounds, portable evidence, plural distributions, contestation |
| SmartVote | political, deliberative | comparative judgment, multiple readings | lens, default, weighting, agenda influence | expertise → political interpretation | baseline preservation, explicit lenses, deterministic calculation |
| Orgo | administrative, operational | assignment, routing, escalation, execution, closure | timing, workload, approval, closure | administration → de facto policy | scoped roles, audit, appeal, revocability, mandate boundary |
| Capsules / federation | technical, infrastructural, evolutionary | deployment, replication, local continuity, substitution | signing, update, registry, compatibility | infrastructure → standards / dependency | verifiable packages, rollback, self-hosting, multiple operators |
| AI | cognitive, epistemic | reasoning, synthesis, translation, modeling | hidden framing, prioritization, interpretive dependency | cognition → judgment / execution | bounded roles, provenance, human/institutional authority |
| Brand / narrative | narrative, attention, network, economic | recognition, affiliation, transmission, fundraising | symbolic legitimacy, gatekeeping, attention | brand → affiliation → revenue / adoption | ethical self-binding, brand ≠ truth, protocol/brand separation |
| Multilingual layer | semantic, distribution | cross-language access, translation, reach | language inclusion/exclusion, translation framing | language → discoverability / standing | explicit source links, review, local semantic control |
| Zero-Skim mechanisms | economic, allocation, political | pooling and allocating resources | allocation, donor/funder leverage | money → projects / infrastructure | one-member-one-vote style safeguards, capital ≠ political standing |
| Koali protocolization | technical, credibility, evolutionary | reproducible credibility capability | registry / compatibility / standing power | founder control → protocol ecology | ownership decoupling, interoperability, branchability |

## The design goal

> **Increase generated puissance aggressively, expose cross-domain conversion, route capability deliberately, and keep resulting power contestable and non-terminal.**
