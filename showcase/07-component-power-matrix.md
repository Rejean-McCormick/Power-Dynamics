# kOA Component Power Matrix

Every kOA component should be read in three steps:

1. **What resource does it organize?**
2. **What puissance does it create?**
3. **What power relations can emerge around successful use?**

| Component | Generated / amplified puissance | Possible power relations | Constitutional counterweights |
|---|---|---|---|
| SemantiK / SenTient | semantic structuration, ambiguity resolution, translation | classification, ontology, admissibility, framing | explicit ontology, provenance, contestable categories, alternatives |
| Kristal | epistemic + mnemonic puissance | canonization, validation, trust-root, standard-setting power | provenance, lineage, reader policies, competing Kristals, portable artifacts |
| Konnaxion | collective, network, communication, discovery puissance | ranking, moderation, access, visibility, agenda power | transparent policies, portability, federation, alternative discovery layers |
| Koali / EkoH | credibility legibility | recognition, standing, certification, opportunity power | domain-bounded criteria, history, plurality of models, contestation |
| SmartVote | comparative and deliberative puissance | lens, default, weighting, discoverability influence | preserve baseline, separate advisory readings, deterministic calculation, explicit lenses |
| Orgo | operational and administrative puissance | routing, assignment, escalation, timing, closure power | scoped roles, audit trails, appeal, explicit workflow rules, revocability |
| Capsules / federation | deployment, replication, substitution, local-operation puissance | signing, update, compatibility, registry power | verifiable packages, rollback, multiple hosts, branchability, key governance |
| AI | cognitive throughput and synthesis puissance | hidden framing, prioritization, interpretation, dependency | bounded roles, provenance, human-governed policy, reproducible non-AI paths where required |
| Brand / narrative | recognition, affiliation, distribution, fundraising puissance | attention, legitimacy-by-association, trademark gatekeeping | separate protocol commons from brand stewardship; brand ≠ truth |
| Multilingual layer | semantic access and distribution puissance | translation framing, language inclusion/exclusion | explicit source links, multilingual review, local semantic control |

## The design goal

> **Increase the left column aggressively while making the middle column legible and the right column effective.**

This is the shortest summary of the repo's normative architecture.
