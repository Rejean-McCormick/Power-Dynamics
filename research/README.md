# Research Layer

This directory is the entry point for external scholarship that can challenge, refine, or situate Power Dynamics.

The structured academic inventory now lives in [`../Academic-Lineage/`](../Academic-Lineage/README.md).

External literature is deliberately separated from the supplied kOA corpus so the repository does not silently replace source-derived concepts with general academic knowledge.

The governing rule is:

> **Academic correspondence is not endorsement, historical influence, or implementation validation.**

Use the literature to identify known failure modes, established mechanisms, impossibility results, and useful comparative vocabulary.
