# Case Studies

Cases are where the Power Show and the analytical theory meet.

Each case should ideally answer:

1. what resources are present;
2. what capability is generated;
3. how that capability composes or compounds;
4. what relations of power emerge;
5. what returns and dependencies follow;
6. what counterpowers and alternatives remain.

The cases are not all equally current. Legacy proposals are retained when they expose useful failure modes, centralization risks, or conceptual evolution.

Notable cases include:

- kOA bootstrap and founder-to-system transition;
- unpublished corpus as epistemic reservoir;
- media vs state as a domain-specific power comparison;
- SmartVote discoverability;
- competing Kristals;
- recognition loops;
- Desjardins power stacking;
- Zero-Skim allocation governance;
- brand, merchandise, and affiliation;
- AI hidden sovereignty;
- KingCoin as a legacy stress test.
