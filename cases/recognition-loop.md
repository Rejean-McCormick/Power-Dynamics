# Recognition Loop and Incumbency

A healthy recognition loop:

`Contribution → Evidence → Recognition → Opportunity → More Contribution`

can become:

`Recognition → Visibility → Opportunity → Recognition`

The second loop lets incumbency reproduce itself even when new evidence is weak. Branch mobility, portable evidence, domain-bounded credibility, time decay, and alternative discovery policies can counterbalance this dynamic.
