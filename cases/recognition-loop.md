# Recognition Loop and Incumbency

A healthy recognition loop can convert contribution into future opportunity:

```text
Contribution
→ Evidence
→ Recognition
→ Contextual Credibility
→ Opportunity
→ More Contribution
→ New Evidence
```

This is useful because it lets strangers cooperate without rebuilding trust from zero.

## The incumbency failure mode

The same loop can collapse into:

```text
Recognition
→ Visibility
→ Opportunity
→ More Visible Evidence
→ More Recognition
```

Then incumbency reproduces itself even when new evidence is weak. Prestige, affiliation, title, wealth, audience, or institutional brand can substitute for current demonstrated relevance.

The inverse loop can exclude unknown actors:

```text
low recognition
→ low visibility / access
→ few opportunities to demonstrate capability
→ thin evidence history
→ low recognition
```

## Countermeasures

- portable evidence;
- domain-bounded credibility;
- time decay where relevant;
- explicit provenance;
- contestation and correction;
- alternative discovery policies;
- opportunities to demonstrate competence directly;
- separation of popularity, credibility, ethics, competence, and legitimacy;
- no universal social-credit score.

The goal is not to erase reputation. It is to keep reputation from becoming a self-sealing permission system.
