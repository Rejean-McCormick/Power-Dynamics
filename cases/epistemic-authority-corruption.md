# Epistemic Authority Corruption Drill

A forkable knowledge system must remain usable even when an actor deliberately tries to make a false worldview look well supported.

Current architect-confirmed design includes an adversarial Kristal centered on a known false conclusion — a flat-Earth worldview — so that the system can study **how apparent knowledge can be manufactured** without ambiguity about the ground truth.

The object of study is not the truth of the flat-Earth claim. The object is the **construction of epistemic authority around it**.

## Power conversion under test

```text
claims / documents / credentials / popularity / citations
→ apparent credibility
→ apparent source multiplicity
→ discoverability and repetition
→ perceived consensus
→ epistemic authority
```

The stress test asks where these conversions become misleading and which controls reveal the distortion.

## Threat classes

The drill is intended to expose classes of corruption such as:

- unverified or fabricated authority claims;
- circular citation;
- dependent sources presented as independent confirmation;
- selective evidence and omitted counterevidence;
- prestige transfer from institutions, titles, or formats;
- popularity treated as evidentiary weight;
- semantic reframing and definition drift;
- repetition interpreted as consensus;
- scientific material quoted or transformed beyond what it actually supports.

This repository treats these as **threat classes**, not as instructions for deceiving external institutions or audiences.

## Apparent independence vs causal independence

A central analytical distinction is:

> **Many references do not imply many independent evidentiary lineages.**

For example:

```text
100 apparent references
→ 12 intermediary summaries
→ 3 shared source chains
→ 1 unsupported origin
```

A robust epistemic system should make this compression visible where provenance allows it.

## Postmortem as the primary output

The valuable artifact is the autopsy:

```text
How did the false conclusion acquire authority?
Which signals were trusted too easily?
Which sources were not actually independent?
Where did provenance become weak or opaque?
Which counterevidence was excluded?
Which detection rules worked?
Which controls failed?
What should change before the same pattern appears in a subtler domain?
```

The result can become a reusable library of epistemic pathologies for later analysis of political propaganda, pseudoscience, commercial persuasion, institutional bias, or other contested knowledge environments.

## Constitutional objective

Forkability permits incompatible representations. It does **not** require equal evidentiary standing.

> **Freedom to maintain a worldview is distinct from immunity from provenance, comparison, contradiction, and evidentiary audit.**
