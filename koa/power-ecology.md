# kOA Power Ecology

A simplified map:

```text
Kristal → reusable epistemic/memory capital
Konnaxion → association, attention and coordination
Koali/EkoH → governed credibility signals
SmartVote → plural readings and discoverability
Orgo → execution and accountability
Capsules/Federation → deployment sovereignty and alternatives
AI → cognitive acceleration under bounded authority
Narrative/Brand → transmission, affiliation and economic conversion
Outcomes → returns → memory / credibility / money / network → next cycle
```

The value of the architecture is not any module alone but the ability of returns from one module to become inputs to another.
