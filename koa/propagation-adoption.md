# kOA Propagation and Adoption

kOA does not need one universal acquisition channel.

Its architecture supports multiple entry paths that can converge on the same knowledge-to-action infrastructure.

## Adoption path

```text
entry surface
→ contextual understanding
→ inspectable evidence
→ bounded trial
→ local value
→ operational continuity
→ independent mastery
→ optional federation
```

## Entry surfaces

- technical code / documentation;
- public-good / sovereignty framing;
- SmartVote / collective judgment;
- Kintsugi integration;
- cultural provenance / Kreative;
- multilingual access / SemantiK;
- education / UCKK;
- concrete operational workflow / Orgo;
- Worlds / scenario-specific demonstrations;
- cultural narrative and media.

## Why local value matters

The propagation model is strongest when an instance can be useful before network scale.

```text
local value
→ independent adoption
→ reproducible instance
→ compatibility
→ optional exchange
→ network value
```

This avoids making federation a prerequisite for first usefulness.

## Why existing systems can strengthen kOA

Kintsugi-oriented integration changes the competitive geometry.

A capable external tool can become:

- a preserved authority;
- an annexed sidecar;
- a data / artifact source;
- a Kompendio reference;
- a complementary capability.

The desired gravity is therefore **articulation by usefulness**, not forced replacement.

## Why SmartVote can strengthen adoption

SmartVote can act as a system-wide discoverability primitive.

As more evaluable objects, domains, evidence, and contribution histories exist, the platform can potentially generate more useful contextual rankings.

That creates a candidate loop:

`objects → evaluation → discovery → reuse → more objects`.

The loop remains legitimate only if raw participation remains visible, expertise is bounded, and ranking policy is inspectable and contestable.

## Why the movement is a test environment

Once multiple independent contributors exist, using kOA to coordinate kOA can test the architecture under real conditions.

The important threshold is not a label such as “movement.” It is **multi-actor autonomous capacity**:

- people can initiate work;
- coordinate;
- preserve memory;
- challenge decisions;
- operate infrastructure;
- train successors;
- continue during founder absence.

That threshold is both an adoption milestone and a founder-decentering milestone.
