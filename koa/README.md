# kOA as a Capability and Power Ecology

This directory is the **systems core of the Power Show**.

kOA is analyzed first as an architecture that can make actors more capable, then as an architecture whose successful capabilities can create consequential relations of power.

The operative loop is:

> **Know → Choose → Act → Remember → Know better**

The Power Show asks:

1. **What new capability does each subsystem create?**
2. **How does that capability compose with other subsystems?**
3. **What returns does successful action preserve?**
4. **How does the result increase later capability?**
5. **Can those returns activate capability in another branch, actor, deployment, or community?**

Power Dynamics then asks:

6. **What power relations arise around successful use?**
7. **What conversion, stacking, capture, or dependency risks appear?**
8. **What counterpowers exist?**
9. **Can alternative branches remain viable and evolve?**

## kOA capability stack

- **SemantiK / SenTient** — semantic puissance;
- **Kristal** — epistemic and mnemonic puissance;
- **Konnaxion** — collective, network, communication, and discoverability puissance;
- **Koali / EkoH** — credibility legibility;
- **SmartVote** — comparative and deliberative puissance;
- **Orgo** — operational and administrative puissance;
- **AI** — cognitive amplification under governance;
- **Capsules / federation** — deployment, substitution, replication, and branch puissance;
- **brand / narrative** — recognition, affiliation, transmission, and economic conversion;
- **multilingual layer** — semantic access and distribution across languages.
