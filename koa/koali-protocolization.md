# Koali: From Property to Protocol

Koali is a critical test of whether kOA merely creates a new credibility center or **shares the capacity to organize credibility**.

The current architect-confirmed design intention is explicit:

> **Koali should not remain an exclusive personal property on which everyone else must depend. Its useful capability should be duplicable, shareable, branchable, and capable of plural distributions.**

This design intent is recorded here separately from source-derived implementation claims. A canonical Koali distribution specification should eventually replace this note as the primary technical evidence.

## Why this matters

Credibility infrastructure can influence:

- discoverability;
- standing;
- opportunity;
- certification;
- access;
- trust;
- collaboration;
- advisory influence.

If one actor permanently owns the only meaningful credibility layer, a mechanism designed to recognize contribution can become a new gatekeeper.

## Protocolization target

```text
founder-created concept
→ explicit kernel / contracts
→ portable evidence and history
→ policy identity
→ multiple distributions
→ interoperability
→ independent operation
→ branch comparison and evolution
```

The political transformation is:

> **Personal ownership of a capability → stewardship of an interoperable protocol ecology**

## What can remain distinct

Power sharing does not require one universal Koali.

Different distributions may legitimately use different criteria for different domains or communities, provided that their policies are explicit enough to interpret.

Examples might include academic, engineering, local-community, professional, artistic, or project-specific credibility distributions.

This is the intended meaning of:

> **Plurality without fragmentation.**

## Minimum power-sharing properties

A mature Koali architecture should make the following possible where technically appropriate:

1. **Reimplementation** — another actor can implement the common logic.
2. **Distribution plurality** — multiple operators can run different credibility policies.
3. **Policy legibility** — a score or signal identifies the policy under which it was produced.
4. **Evidence portability** — underlying evidence can be reused without recreating a person's entire history from zero.
5. **Contestability** — signals can be challenged or corrected.
6. **Interoperability** — distributions can exchange or compare structured evidence without pretending they are identical.
7. **Discoverability of alternatives** — one dominant distribution does not become the only socially visible one by default.
8. **Branch mobility** — an improved distribution can gather adoption and become viable.

## Constitutional limit

> **Credibility signal ≠ person ≠ competence ≠ ethics ≠ truth ≠ sovereignty.**

Koali is strongest as infrastructure when it helps other actors make informed judgments while refusing to become the unique owner of social legitimacy.
