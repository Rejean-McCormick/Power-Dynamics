# Propagation

This directory studies how capability becomes easier to activate **elsewhere**.

Power Dynamics already treats returns and reinvestment as sources of compounding. Propagation adds a different question:

> **When can a return generated in one actor, branch, domain, or deployment increase the effective possibility of capability in another?**
