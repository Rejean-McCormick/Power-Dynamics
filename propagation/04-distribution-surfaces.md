# Distribution Surfaces

A complex infrastructure can fail to propagate even when it is technically useful because explanation itself does not scale.

kOA uses or proposes several distinct **distribution surfaces**.

## Human-facing surfaces

- institutional briefs;
- public websites;
- technical repositories and wikis;
- Medium-style essays and academic articles;
- books;
- albums / songs;
- podcasts;
- fictional / symbolic narrative;
- scenario mosaics;
- seeded Worlds;
- deterministic cinematic demonstrations.

The purpose of multiple surfaces is not to repeat the same pitch everywhere. It is to let different audiences enter through a format they can parse while preserving a shared factual spine.

## Machine-facing surfaces

- structured Markdown;
- explicit source maps;
- context packs;
- stable schemas;
- machine-readable indexes;
- `llms.txt`-style entry points or equivalent concise machine-oriented maps.

These can reduce the cost for a third party to use its own AI system to inspect the corpus.

## Distribution loop

```text
structured corpus
→ lower explanation / due-diligence cost
→ more independent examination
→ more criticism / questions / evidence
→ better corpus
→ lower future explanation cost
```

## Worlds and cinematic demonstrations

Architect-confirmed current tooling includes seeded Worlds and a cinematic demonstration pipeline. Their propagation role is specific:

```text
real sources
→ structured World
→ populated environment
→ scripted interaction
→ understandable demonstration
```

A World can solve the **empty-platform demonstration problem** by showing a context already populated with recognizable objects.

A cinematic pipeline can reduce the marginal cost of explaining that World to many audiences.

Neither mechanism proves adoption. Their value is measured by downstream conversion:

`demo → examination → pilot → deployment`.

## Convergence requirement

Many entry points create a maze risk.

The communication architecture should therefore follow:

> **Multiplicity at the periphery; simplicity and traceability at the center.**

Every narrative or media corridor should make it possible to reach the canonical architecture, evidence, status, and limitations.
