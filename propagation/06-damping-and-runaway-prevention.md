# Damping and Runaway Prevention

Positive feedback is not automatically desirable.

Without damping, compounding can become:

- incumbency;
- lock-in;
- metric gaming;
- prestige reproduction;
- founder centrality;
- monopolistic standards power;
- misinformation amplification;
- administrative overreach;
- uncontrolled complexity;
- operational overload.

## Governor pattern

A propagation mechanism should be paired with at least one countervailing mechanism.

| Positive loop | Runaway risk | Governor |
|---|---|---|
| SmartVote recognition | prestige becomes permanent authority | domain bounds, time decay, raw baseline, audit |
| Managed-service revenue | money buys unrelated control | authority separation; funding ≠ votes |
| Brand attention | persona becomes truth source | traceability to evidence; brand ≠ protocol |
| Kintsugi integration | interface layer becomes mandatory choke point | replaceable adapters, explicit boundaries, direct exit |
| Federation | de facto center dominates local nodes | local authority, optional federation, forkability |
| AI production | quantity overwhelms validation | provenance, tests, human review, publication gates |
| Documentation growth | information overload | canonical entry points, progressive disclosure |
| Founder recognition | personal interpretation becomes constitutional | founder decentering, opposition, maintainer pluralism |
| Language expansion | nominal support outruns quality | conformance tiers, native review, published coverage |
| World generation | simulation mistaken for evidence | explicit simulation/reconstruction/live labels |
| Outreach | contact mistaken for endorsement | evidence-state tracking |

## Pace is also a control surface

A healthy architecture does not require continuous acceleration.

Branches can pause, remain local, defer federation, or allow the founder or maintainers to step back temporarily.

This is a resilience feature when the system can preserve state and continue safely without constant central intervention.

## Canonical condition

> **The system should be able to accumulate capability without requiring the same rate of accumulation in centralized authority, dependency, or founder attention.**
