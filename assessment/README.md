# Assessment

Assessment begins with **capability**, not suspicion.

The method first asks what a system genuinely enables. Only then does it map the power relations, dependencies, conversion pathways, and constitutional risks created by that capability.

The preferred sequence is:

1. baseline problem and constrained possibilities;
2. resources / stock;
3. potential;
4. capacity;
5. puissance generated or amplified;
6. composition with other capabilities;
7. mobilization and throughput;
8. power relations created;
9. effects and returns;
10. reinvestment and compounding;
11. conversion pathways;
12. concentration / stacking / capture;
13. dependency and bottlenecks;
14. counterpowers;
15. branch alternatives and branch mobility;
16. temporal evolution and decay;
17. constitutional requirements.

Assessment is qualitative-first. The repository does not assume that power, competence, legitimacy, ethics, branch quality, or systemic value can be reduced to universal scalar scores.
