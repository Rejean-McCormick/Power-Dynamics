# Flow, Conversion, Stacking, and Capture Audit

This audit combines the stock/flow, conversion, and stacking views.

## Stock → Capacity → Flow

For each major resource, trace:

`Stock → Potential → Capacity → Puissance → Flow → Relation → Return`

## Conversion map

List all material conversions and intermediate steps. Example:

`expertise evidence → credibility signal → ranking weight → discoverability → opportunity`

Ask who controls each step, whether the conversion crosses domains, whether it is contestable, and whether an alternative branch can implement a different policy.

## Stacking

Inventory every function held by the same actor or node. Ask what leverage appears only because several legitimate functions are combined.

## Capture

Test whether functional control has become durable cross-domain power:

`Functional Control → Cross-Domain Power`

Document mandate drift, default expansion, dependency growth, recognition loops, reduced branch mobility, and rising exit costs.
