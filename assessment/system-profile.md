# System Power Profile

A system profile should summarize major resource stocks, main forms of puissance, major power relations, mediators and bottlenecks, conversion pathways, return loops, concentration, stacking, dependency gradients, counterpowers, branch ecology, founder/maintainer dependencies, temporal risks, and technical-evidence confidence.

This is the preferred top-level audit output.
