# Temporal Evolution Analysis

Power relations change over time.

### Formation phase
Who supplies scarce initial capability?

### Scaling phase
Which feedback loops, network effects, standards, and dependencies emerge?

### Succession / maturity phase
Can authority, knowledge, keys, brand stewardship, and maintenance transfer without collapse?

Also inspect decay: credibility can expire, technical knowledge can become obsolete, and branches can lose fitness. A static snapshot is insufficient.
