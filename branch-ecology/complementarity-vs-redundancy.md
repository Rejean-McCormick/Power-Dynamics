# Complementarity vs Redundancy

Plurality adds value when branches reveal different evidence, contexts, trade-offs, methods or functions. Repetition that produces no new evidence, interpretation, capability or test adds little collective value.

A scientific branch, legal branch, local-experience branch and historical branch can all be useful if each exposes what the others omit. This is **complementarity**.

The system should therefore ask of a new branch:

- What difference does it preserve?
- What evidence or context does it add?
- What capability becomes possible because it exists?
- Can the new value be recombined with other branches?

The anti-dogmatic principle is not "everything is equally true." It is that no branch gains final authority merely by repetition, incumbency or official status.
