# Branch Ecology

Branch ecology is the **evolutionary end of the Power Show**.

A system is more capable when it can not only act, but also **improve the mechanisms through which it knows, chooses, acts, and remembers**.

Branches are therefore not merely emergency responses to capture. They are normal instruments of experimentation under permanent imperfection.

The ecology asks:

- how lineage and competing Kristals are preserved;
- how complementarity avoids dogma without collapsing into relativism;
- how alternatives demonstrate added value;
- how support, adoption, dominance, truth, and quality remain distinct;
- whether a better branch can actually become viable;
- how branches coexist, specialize, recombine, merge, or replace one another.

The key capability is **branch mobility**: not only the formal right to fork, but the practical ability to preserve provenance, interoperate, attract support, gain discoverability, and eventually influence or replace a dominant branch.

> **The core protects evolution; it does not freeze truth.**
