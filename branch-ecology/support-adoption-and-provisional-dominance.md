# Support, Adoption, and Provisional Dominance

Branches accumulate different kinds of support: users, experts, institutions, evidence, resources, compatible tools and network effects.

A dominant branch is simply one with greater practical standing under some combination of these dimensions. Dominance does not imply truth or perfection.

Power Dynamics therefore tracks *why* a branch is dominant. It may dominate because it performs better, because it is easier to use, because institutions trust it, because it controls a bottleneck, or simply because incumbency makes migration expensive.

Only the first reasons are strong evidence of fitness; the others may reflect power rather than quality.
