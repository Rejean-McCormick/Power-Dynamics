# Branch Mobility in Practice

Branch mobility is the practical path from alternative to viable competitor or complement.

A high-mobility ecosystem lets a branch:

`form → preserve lineage → interoperate → demonstrate → be discovered → gather support → deploy → influence / coexist / replace`.

Low branch mobility can create dogma without explicit censorship: alternatives formally exist but cannot accumulate enough recognition, compatibility, or infrastructure to matter.
