# The kOA Power Surface

A **power surface** is any function, interface, role, registry, workflow, standard, narrative, resource rail, or infrastructural boundary through which control can materially alter effective possibility.

The kOA Power Show is strongest when it makes the whole surface visible at once.

> **kOA is powerful because it can create capability across many domains and connect those domains into conversion and feedback loops.**

## Master map

| Domain | Generated puissance | Relational power that may emerge | Typical conversion outward | kOA routing / firewall direction |
|---|---|---|---|---|
| Epistemic | validate, compare, preserve, reuse knowledge | validation, canon, trust-root | knowledge → credibility | portable artifacts, provenance, competing Kristals |
| Semantic | structure concepts, categories, translation, ambiguity | classification, framing, admissibility | meaning → agenda / enforcement | versioned semantics, local governance, contestation |
| Cognitive / AI | reasoning, synthesis, modeling, translation | hidden framing, prioritization, dependency | cognition → judgment / execution | AI under explicit governance, bounded authority |
| Information / attention | publish, search, rank, distribute, amplify | visibility, agenda, moderation | attention → affiliation / legitimacy / funding | explicit discovery policies, alternatives, export |
| Credibility / reputation | make evidence of competence/contribution legible | standing, certification, opportunity | credibility → visibility / access | domain-bounded signals, plural models, contestation |
| Network / affiliation | association, brokerage, recruitment, diffusion | inclusion, exclusion, access | network → execution / opportunity | portable identity/relationships where feasible, plural networks |
| Political / constitutional | deliberate, decide, authorize, amend, govern | mandate, veto, legitimacy, decision | political → administrative / allocation | political equality, scoped authority, contestation |
| Economic | mobilize scarce resources, assets, labor, funding | bargaining, ownership, allocation | money → infrastructure / reach | democratic allocation, anti-pay-to-rule firewalls |
| Monetary | liquidity, exchange, payment, credit, settlement | issuance, rail, reserve, access | monetary → economic / political dependency | treat high-stack monetary designs as constitutional risk |
| Administrative / operational | assign, route, schedule, escalate, close | timing, workload, approval, closure | administration → de facto policy | explicit workflows, audit, appeal, revocability |
| Technical / infrastructural | build, deploy, verify, operate, reproduce | compatibility, update, identity, dependency | infrastructure → standards / access | self-hosting, capsules, federation, substitution |
| Narrative / symbolic / brand | memory, attention, affiliation, transmission | framing, legitimacy-by-association, gatekeeping | brand → attention → revenue / adoption | ethical self-binding, brand ≠ truth, protocol separation |
| Mnemonic / temporal | preserve reasons, outcomes, precedent, timing | precedent, delay, succession | memory → future agenda / legitimacy | provenance, versioning, alternative histories |
| Evolutionary / counterpower | fork, substitute, recombine, replace | displacement of incumbents | alternative → support → dominance | branch mobility, lineage, interoperability |

## Why breadth matters

A system that is powerful in one domain can still be constrained by other systems. A system that touches many domains can create much larger **cross-domain leverage**.

For example:

```text
semantic control
→ epistemic interpretation
→ credibility
→ visibility
→ agenda
→ political influence
```

or:

```text
money
→ infrastructure
→ distribution
→ attention
→ affiliation
→ political leverage
```

or:

```text
technical control
→ defaults
→ dependency
→ administrative necessity
→ de facto governance
```

The same breadth that makes kOA capable is therefore the reason it needs explicit constitutional design.

## Political surface

kOA can influence political capacity through:

- issue formation and semantic framing;
- discoverability and agenda formation;
- credibility and advisory signals;
- deliberation and proposal comparison;
- voting / reading mechanisms;
- resource allocation;
- workflow and execution;
- memory and precedent;
- branch evolution and institutional alternatives.

Political power therefore begins **before the vote** and continues **after the vote**.

## Economic surface

Economic puissance includes the ability to mobilize:

- money;
- property;
- productive assets;
- labor and time;
- infrastructure;
- funding;
- contracts;
- procurement;
- philanthropy;
- bargaining position.

kOA can increase economic capability by improving coordination, credibility, discoverability, resource pooling, allocation, execution, and compounding.

## Monetary surface

Monetary power is narrower than economic power. It concerns control over:

- issuance;
- units of account;
- liquidity;
- payment rails;
- settlement;
- reserves;
- credit and debt conditions;
- convertibility;
- transaction access.

A monetary layer can become extraordinarily powerful because it conditions other domains. This is why the legacy KingCoin proposals are useful as a **stacking stress test**, not as current constitutional doctrine.

## The core constitutional question

For every surface, ask:

1. **Who gains capability?**
2. **Who gains authority?**
3. **Who receives returns?**
4. **Who gains optionality?**
5. **What other domain can this convert into?**
6. **What prevents that conversion from becoming arbitrary?**
7. **Can affected actors verify, contest, substitute, exit, or fork?**

The desired architecture is not flatness. It is a **governable ecology of strong capabilities and non-terminal asymmetries**.
