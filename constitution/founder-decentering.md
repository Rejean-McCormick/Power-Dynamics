# Founder Decentering

Founder power can arise from authorship, vocabulary, repositories, domains, brand, relationships, keys, architecture knowledge, and interpretive authority.

The goal is not necessarily founder removal. It is independent reproducibility:

> **Founder → Architecture → Distributed Mastery**

rather than:

> **Founder → Permanent Interpretive Dependency**

Useful phases include founder sovereignty, constitutional constraints, maintainer pluralism, institutional federation, and protocol-level continuity.


## Power redirection, not only founder limitation

Founder decentering can be designed as a productive conversion rather than simple loss of control:

```text
founder knowledge
→ documentation / schemas / protocols
→ shared implementation capacity

founder infrastructure
→ portable deployments / federation
→ local operational autonomy

founder-created credibility mechanism
→ interoperable Koali distributions
→ plural credibility capacity

founder narrative
→ published ethical constraints
→ public self-binding and reinterpretability
```

This is **power redirection**: leverage that could remain attached to the founder is converted into capability that other actors can reuse independently.
