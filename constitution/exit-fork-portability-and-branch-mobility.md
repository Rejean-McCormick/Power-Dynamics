# Exit, Fork, Portability, and Branch Mobility

A formal right to fork is not enough.

**Effective forkability** requires that an alternative can preserve or reconstruct the resources necessary to continue: data, knowledge artifacts, provenance, identity where appropriate, configuration, documentation, deployability and enough interoperability to communicate with the wider ecosystem.

Power Dynamics adds **branch mobility**: the practical capacity of an alternative branch to become significant if it demonstrates value.

Branch mobility depends on:

- discoverability of alternatives;
- compatibility with shared artifacts;
- migration paths;
- transparent comparison;
- ability to accumulate support;
- absence of exclusive infrastructure bottlenecks;
- ability to attract maintainers and institutions.

A system may be open source while still having very low branch mobility because network effects, trademark control, hosting, signing keys or identity infrastructure keep one branch effectively sovereign.
