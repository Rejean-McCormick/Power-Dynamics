# Power-Conversion Firewalls

A conversion firewall permits useful composition while blocking automatic cross-domain authority.

Canonical examples:

- `Expertise → Advice`, not `Expertise → Sovereignty`.
- `Money → Funding`, not `Money → More Votes`.
- `Brand → Attention`, not `Brand → Truth`.
- `Technical Administration → Maintenance`, not `Administration → Political Outcome Control`.
- `Credibility → Discoverability`, not `Credibility → Unquestionable Authority`.

Firewalls should be auditable and testable at implementation level, not only stated as principles.
