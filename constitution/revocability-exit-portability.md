# Revocability, Reversibility, Exit, Fork, and Portability

Revocation removes future authority. Reversal addresses prior effects. They are different.

A ranking rule can be changed while earlier reputational effects persist. A decision-maker can be removed while contracts, debts, or standards remain.

Exit and fork are structural counterpowers only when effective. Portability can include data, knowledge artifacts, identity, credentials, reputation evidence, decision history, operational records, schemas, protocols, and deployment tooling.

A technically forkable project can remain practically monopolistic if forks lose recognition, network access, compatibility, or essential assets.

Constitutional analysis should therefore ask both whether authority can be revoked and whether affected actors can actually migrate, recover, or continue.
