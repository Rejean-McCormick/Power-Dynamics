# Repository Status

Power Dynamics is an analytical reconstruction of a heterogeneous corpus. The corpus contains foundational books, current architecture descriptions, academic-style analyses, experimental designs and older proposals that are not necessarily compatible with later principles.

## Maturity labels

- **CURRENT-CORE** — repeated and structurally consistent with recent kOA architecture.
- **CURRENT-EXPERIMENTAL** — active design direction, but its governance or implementation remains open.
- **OPEN-QUESTION** — deliberately unresolved.
- **LEGACY-PROPOSAL** — historically present, retained for analysis rather than treated as present doctrine.

## Claim-type labels

- **SOURCE-DERIVED** — directly supported by supplied source material.
- **ANALYTICAL-RECONSTRUCTION** — synthesized across sources.
- **NEW-CONCEPT** — vocabulary introduced in Power Dynamics to improve analysis.
- **EXTERNAL-RESEARCH** — reserved for later work grounded in outside literature.

## Major historical tension

Several older economic documents imagine strong centralized coordination, global monetary governance, automated sanctions or blacklisting. More recent texts emphasize non-domination, local operability, semantic sovereignty, contestability, multiple readings, portability and bounded expertise. The repository treats this as an evolution in the power model and as a useful stress test, not as a contradiction to be silently erased.
