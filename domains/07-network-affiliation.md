# Network and Affiliation Power

Network puissance is the ability to mobilize relationships for access, diffusion, recruitment, coalition, collaboration, or action.

## Resources

- relationships;
- memberships;
- trust links;
- brokerage positions;
- audiences;
- institutional access;
- affiliation with brands or communities.

## kOA effects

Konnaxion, brand, public contribution, credibility, and project collaboration can convert isolated capability into networked capability.

```text
knowledge → contribution → recognition → network → opportunity → execution
```

## Relational powers

- brokerage power;
- inclusion / exclusion power;
- affiliation power;
- recruitment power;
- access power.

Network power compounds because every successful collaboration can create new future pathways.
