# Mnemonic and Temporal Power

Mnemonic puissance is the ability to preserve and reuse reasons, knowledge, decisions, actions, failures, provenance, and outcomes across time.

## Compounding role

```text
action
→ experience
→ memory
→ lower future coordination cost
→ better action
```

Memory is therefore a production factor, not merely an archive.

## Relational power

Control of memory can shape:

- precedent;
- institutional interpretation;
- which failures are remembered;
- which actors receive recognition;
- what counts as historical continuity.

Temporal power also includes control over timing, delay, deadlines, release, expiry, succession, and disclosure.

## Counterpower

Provenance, versioning, portable history, alternative representations, succession planning, and release optionality make temporal power more governable.
