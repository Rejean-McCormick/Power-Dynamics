# Technical and Infrastructural Power

Technical puissance is the ability to build, modify, verify, deploy, repair, and reproduce systems. Infrastructural puissance is capability created by reliable shared systems and protocols.

## Power surfaces

- code repositories;
- signing keys;
- identity rails;
- registries;
- APIs;
- standards;
- deployment topology;
- hosting;
- update channels;
- compatibility rules.

## Relational powers

- access power;
- compatibility power;
- update power;
- dependency power;
- standards power.

## kOA routing direction

Self-hosting, offline capability, capsules, verification, rollback, federation, portability, and substitution seek to convert infrastructure into **local capability rather than terminal operator dependency**.

> **Instance capture ≠ system capture.**
