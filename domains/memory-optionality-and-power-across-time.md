# Memory, Optionality, and Power Across Time

Memory is power across time. It allows future actors to inherit evidence, reasoning, decisions, failures and methods instead of resetting to near-zero.

Optionality is the value of preserving multiple future paths. Money, privacy, portable data, unused institutional access or an unexercised right can all function as options. Exercising an option may create immediate power while destroying future optionality.

Power analysis should therefore ask not only what an actor can do now, but which future possibilities an action preserves or closes.
