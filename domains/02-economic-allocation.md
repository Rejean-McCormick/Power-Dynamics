# Economic and Allocation Power

Economic puissance is the effective ability to mobilize scarce material resources for action. Economic power appears when control of resources changes others' access, bargaining position, options, or dependency.

## Resources

- money;
- property;
- productive assets;
- labor and time;
- contracts;
- funding;
- procurement;
- infrastructure;
- philanthropy;
- market access.

## kOA pathways

```text
knowledge → credibility → opportunity → income
network → collaborators → execution → output → funding
brand → attention → affiliation → revenue
money → infrastructure → capability
collective activity → returns → shared assets → greater future capability
```

## Allocation power

Allocation power is the relational power to determine which people, projects, institutions, or goals receive resources.

Zero-Skim is important because it attempts to route:

> **Economic contribution → common resource pool → democratic allocation**

rather than:

> **Economic contribution → proportional political authority**

## Main risks

- donor / funder capture;
- capital → governance conversion;
- infrastructure dependency;
- property bottlenecks;
- returns flowing narrowly to an operator instead of participants.
